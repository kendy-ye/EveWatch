# 客户端预览设计

## 1. 目标

把当前的「客户端预览」实验窗升级为正式的常驻功能：

- 软件启动后默认开启预览
- 每个角色一个独立预览窗口，可放在任意显示器的任意位置
- 预览窗口位置、宽高持久化，重启后恢复
- 全局透明度设置，每个角色可单独控制是否显示预览
- 当前焦点账号的预览窗显示彩色边框，颜色可自定义，默认绿色
- 预览窗口宽高可调，并持久化

## 2. 现状与结论

当前实验版本是「一个窗口 + 多格 DWM 缩略图」。实测 10 个客户端、20 个 ROI 监控下，预览开启/关闭 CPU 分别为 1047 ms / 1062 ms（10 秒采样），内存 244.7 MB / 246.7 MB，开销在噪声范围内。

但「每个预览可以自由摆放」要求每个角色是独立窗口：

- DWM 缩略图的目标窗口必须是顶层窗口，不能是子窗口
- 多格单窗口只能整体移动，无法逐格摆放
- 因此改为：**每个角色一个无边框顶层预览窗**，由管理组件统一创建、定位和销毁

这与 EVE-O Preview 的做法一致。EVE-O Preview 同样使用 DWM 缩略图，其说明文档中截图渲染方案在 3 个缩略图时约占 180 MB，而 DWM 方案约 50 MB。

## 3. 架构

```text
AccountDirectory ──窗口增删──┐
                             ├─> ClientPreviewManager ──> ClientPreviewWindow × N
UiState.ClientPreview ──配置──┘            │
                                           ├─ 前台窗口变化（WinEvent）
                                           └─ 活动边框 / 显示隐藏 / 位置尺寸持久化
```

### 3.1 组件

| 组件 | 位置 | 职责 |
|---|---|---|
| `ClientPreviewState` | `Core/Config/UiState.cs` | 全局开关、默认宽高、透明度、边框颜色、每角色位置与显示状态 |
| `ClientPreviewManager` | `App/Preview/` | 根据窗口快照创建/隐藏/销毁预览窗，维护前台账号，应用设置 |
| `ClientPreviewWindow` | `App/Windows/` | 单个角色的预览窗：DWM 缩略图、边框、名称条、拖动、缩放、点击激活 |
| `ClientPreviewSettingsWindow` | `App/Windows/` | 全局设置与逐角色列表 |

### 3.2 前台账号识别

- 用 `SetWinEventHook(EVENT_SYSTEM_FOREGROUND)` 监听前台窗口变化
- 前台窗口句柄与 `AccountDirectory.Windows` 比对，得到当前账号
- 事件丢失时用 500 ms 定时器兜底
- EveWatch 自己是前台时，保留上一个活动账号的边框高亮

## 4. 单个预览窗

### 4.1 结构

```text
┌─────────────────────────────┐  ← 完全无边框，缩略图铺满客户区
│ TieTouWa A                  │  ← 角色名（整名粗体）覆盖在画面左上角
│                             │
│      DWM 缩略图区域          │
│                             │
└─────────────────────────────┘
  ↑ 只有当前焦点账号的覆盖层画 2px 活动色描边
```

- 无系统标题栏、无边框、不进入任务栏
- 角色名与焦点描边画在独立的透明覆盖窗（`PreviewLabelWindow`）里，鼠标事件穿透到预览窗
- 默认置顶
- 缩略图铺满整个客户区，不再为名称条预留高度

### 4.2 交互

| 操作 | 行为 |
|---|---|
| 左键单击 | 激活对应 EVE 客户端，并把该预览切为活动描边 |
| 右键按住拖动 | 移动预览窗；松手后保存位置（没有右键菜单） |
| 拖动窗口边缘 | 调整宽高；停止拖动 350 ms 后保存尺寸 |

左键不参与拖动；移动超过 4 px 后松手不算单击，不会切换客户端。

### 4.3 尺寸与位置

- 默认 `260 × 170`（含名称条）
- 设置里修改默认宽高后立即应用到所有预览窗（覆盖逐角色尺寸），位置保持不变
- 最小 `140 × 100`，最大 `800 × 600`
- 位置以 WPF 单位保存；首次显示后再用 `SetWindowPos` 按当前 DPI 落一次物理坐标，
  避免多显示器 / 缩放下 WPF 把首次显示的窗口放到默认级联位置
- 显示器被拔掉或分辨率变化时，夹紧到虚拟桌面可见范围，至少保留 48 px 在屏幕内
- 没有保存位置的新角色：从主屏工作区左上角开始，每行 5 个，排满换行
- 恢复时按窗口所在显示器 DPI 换算；混合 DPI 显示器下位置可能有少量偏差，以物理坐标为准

### 4.4 显示规则

- 客户端运行且该角色勾选「显示预览」时才显示
- 客户端离线：隐藏预览，保留位置与尺寸
- 客户端最小化：默认隐藏预览（DWM 对最小化窗口可能停止更新）；设置中可改为「保持显示」
- 停在登录 / 角色选择界面（标题只有 `EVE`，还没有角色名）的客户端：不进入账号列表与逐角色配置，
  首次出现时放在主屏工作区左上角，多个按顺序向下排列；可以右键拖动，位置只在本次运行内保留；
  进入游戏后该预览自动关闭，由正常角色预览接管
- 全局面板关闭时销毁全部预览窗，不影响 ROI 监控

### 4.5 活动描边与角色名

- 完全无边框：非焦点账号的预览没有任何边框
- 当前前台账号：覆盖层画 2px 描边，颜色默认 `#3DDC84`（绿色），可自定义
- 描边粗细可调 `0–6 px`
- 角色名统一颜色（默认 `#E3EBF2`），整名粗体，覆盖在画面左上角
- 颜色、粗细修改后立即应用到所有预览窗

## 5. 配置模型

写入 `evewatch.ui.json`，不进入 `evewatch.json`：

```json
"clientPreview": {
  "topmost": true,
  "showLabel": true,
  "hideWhenMinimized": true,
  "defaultWidth": 260,
  "defaultHeight": 170,
  "opacity": 0.95,
  "activeBorderColor": "#3DDC84",
  "activeBorderThickness": 2,
  "labelColor": "#E3EBF2",
  "accounts": {
    "TieTouWa A": {
      "visible": true,
      "left": 2800,
      "top": 12,
      "width": 260,
      "height": 170,
      "opacity": null
    },
    "String A": {
      "visible": false,
      "left": 2800,
      "top": 192,
      "width": 260,
      "height": 170,
      "opacity": 0.8
    }
  }
}
```

规则：

- 总开关不落盘：软件每次启动默认开启，主工具栏按钮只影响本次运行
- `opacity`：`null` 表示跟随全局；范围 0.3–1.0
- `visible`：逐角色显示开关，默认 true
- 尺寸与坐标启动时 `Normalize`：夹紧、修正非法值
- 未知角色条目保留，客户端重新出现时恢复
- 缺少整个 `clientPreview` 节点时使用默认值

## 6. 设置界面

入口：

- 主工具栏「客户端预览」按钮：总开关，文案随状态变为「客户端预览 · 开」
- 按钮右侧齿轮：打开设置窗口
- 预览窗右键菜单「预览设置」：同一入口

布局（`ClientPreviewSettingsWindow`）：

```text
┌ 客户端预览设置 ──────────────────────────────┐
│ 全局                                          │
│  显示预览 [✓]        置顶显示 [✓]             │
│  默认宽 [260] × 高 [170]  回车即应用到所有预览窗│
│  透明度 [====----] 95%                        │
│  焦点描边颜色 [■] #3DDC84  ■ ■ ■ ■ ■ ■        │
│  焦点描边粗细 [==----] 2px                    │
│  角色名颜色  [■] #E3EBF2  ■ ■ ■ ■ ■ ■        │
│  [✓] 角色名（左上角，粗体）                    │
│  [✓] 最小化时隐藏                             │
│  [自动排列] [重置全部位置]                     │
├───────────────────────────────────────────────┤
│ 角色预览                                      │
│ 角色        显示  宽    高    透明度   位置    │
│ TieTouWa A  [✓]  260   170   跟随     2800,12 │
│ String A    [✓]  260   170   80%      2800,192│
│ String B    [ ]  260   170   跟随     —       │
│ ...                                     [重置]│

└───────────────────────────────────────────────┘
```

实现要点：

- 所有修改立即生效并写回 `evewatch.ui.json`（600 ms 防抖）
- 逐角色透明度档位：跟随 / 90% / 80% / 70% / 60%
- 打开设置面板不会为离线角色创建配置项；只有用户实际修改该行时才落盘
- 拖动预览窗时设置面板的位置列实时刷新

## 7. 性能与闪烁治理

- 每个预览窗只注册一个 DWM 缩略图，画面由 DWM 合成，不经过 WGC，不复制帧
- 前台监听使用 WinEvent，不轮询窗口内容
- 10 个客户端的实测开销已在噪声范围内；预计 20 个客户端仍低于 1% 单核
- 内存增量主要来自 N 个顶层窗口与 WPF 视觉树，预计每个窗口 < 1 MB

闪烁的三个来源与处理：

1. **覆盖层与预览窗抢 Z 序**：以前覆盖层靠 `SetWindowPos(HWND_TOPMOST)` 反复提到最前，
   点击预览窗或切前台时名字会被缩略图盖住再被提回，表现为名字闪一下。
   现在覆盖层是预览窗的 owned window，天然始终在预览窗之上，不再调整 Z 序。
2. **重复喂 DWM**：每次目录快照变化都会对所有预览窗重新应用设置。以前无条件调用
   `DwmUpdateThumbnailProperties`，目标矩形没变也会触发一次重新合成。
   现在缓存目标矩形与透明度，只在真正变化时更新。
3. **无意义的覆盖层重绘**：颜色、可见性、描边值都做了变更比较；覆盖层位置按物理矩形
   比较，未移动时不调用 `SetWindowPos`；显示前先 `AlignTo`，避免第一帧出现在 (0,0)。

仍会有正常视觉变化：拖动/缩放过程中的跟随、客户端最小化/恢复时的显示与隐藏、
切换焦点时描边的位移。

## 8. 已知限制

- 最小化客户端的 DWM 缩略图可能冻结或黑屏，默认隐藏该预览
- 预览窗完全无边框；焦点描边与角色名由每个预览窗的透明覆盖窗绘制，鼠标可穿透
- 同一窗口内不能叠加 WPF 文字（DWM 会盖住），所以标注必须走独立覆盖窗
- 透明度只作用于缩略图画面；窗口整体设为半透明会让 DWM 缩略图在分层窗口里失效
- 混合 DPI 的多显示器下，保存的 WPF 坐标在换算回物理像素时可能有少量偏差
- 客户端处于独占全屏时无法注册缩略图，窗口内会显示「无法预览」
- 需要桌面合成（Win10/11 默认开启）

## 9. 验收标准

- [x] 启动软件后默认显示所有已勾选角色的预览
- [x] 每个预览可拖到任意显示器，重启后位置一致
- [x] 宽高可调，重启后保持；超出屏幕时自动夹紧
- [x] 全局透明度与逐角色透明度生效并持久化
- [x] 逐角色「显示预览」开关立即生效
- [x] 当前前台客户端预览窗显示绿色边框，其他为深色
- [x] 边框颜色修改后立即应用到所有预览窗
- [x] 客户端离线/最小化时按规则隐藏，恢复后回到原位置
- [x] 关闭总开关后所有预览消失，重新开启后恢复布局
- [x] 10 个客户端预览开启/关闭的 CPU 差值在 1% 单核以内

## 10. 实现状态

已实现：

1. `UiState.ClientPreview`：全局设置 + 逐角色布局，带 `Normalize`
2. `ClientPreviewManager`：按窗口快照创建 / 绑定 / 显示 / 隐藏，启动默认开启，600 ms 防抖保存
3. `ClientPreviewWindow`：完全无边框顶层窗、铺满客户区的 DWM 缩略图、左右键拖动、边缘缩放、点击激活
4. `PreviewLabelWindow`：独立透明覆盖层，鼠标穿透；画角色名（左上角、粗体、统一颜色）与焦点描边
5. 前台监听：`SetWinEventHook(EVENT_SYSTEM_FOREGROUND)` + 700 ms 定时兜底，活动描边即时切换
6. `ClientPreviewSettingsWindow`：全局设置、两种颜色（描边 / 角色名）预设与 HEX、逐角色列表与重置
7. 首次布局：主屏左上角起每行 5 个；自动排列、全部重置、单窗重置、虚拟桌面夹紧

待用户实机验证：拖动 / 缩放后的重启还原、透明度观感、混合 DPI 下的位置偏差。
